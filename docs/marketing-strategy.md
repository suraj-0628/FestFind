# Marketing Strategy — College Fest Hub

## Phase 1: Seed & Validate (Weeks 1–4)

| Tactic | Execution |
|---|---|
| **College Ambassador Program** | Recruit 1 ambassador per top-50 engineering colleges. Give them a shareable link with tracking. Reward: "Ambassador of the Month" badge + swag. |
| **WhatsApp / Telegram Groups** | Create group for each major city (Pune, Bangalore, Delhi, etc.). Post daily "Event of the Day". Viral loop: members invite friends. |
| **Instagram Reels / Shorts** | 15-sec clips showing the 3D map with event pins glowing. Hook: "Find fests near you in 3D 🚀" |
| **Reddit (r/Indian_Academia, r/developersIndia)** | Post a Show & Tell with a screen recording of the 3D map. Ask for feedback. Don't hard-sell. |

## Phase 2: Growth Loops (Weeks 5–12)

| Tactic | Execution |
|---|---|
| **"Share this Fest" Widget** | Every event page has a one-click share → WhatsApp/Insta/Twitter. Share generates an image of the event with a QR code to the site. |
| **SEO Play** | Each event gets its own URL with SEO-friendly slug. City pages (e.g., `/city/pune`) aggregate events. Target keywords: "college fests in pune 2026", "tech fests in india". |
| **Embeddable Widget** | Colleges can embed a "Fests near you" widget on their own site. Backlink + free traffic. |
| **Student Newsletter** | Weekly email: "Top 5 fests this weekend". Collect emails via a "Notify me" CTA on the map. |

## Phase 3: Monetization & Moats (Month 4+)

| Tactic | Execution |
|---|---|
| **Featured Event (Paid)** | Event organizers pay ₹499 to pin their event at the top of the map + get a "Featured" glow animation. |
| **Poster Auto-Gen (Freemium)** | Generate Instagram-ready event posters from event data. Free with watermark, paid removes it. |
| **College Tie-ups** | Sell "College Fest Hub Pro" to college admin — embedded event management + analytics dashboard. |

## Channels Summary

- **Instagram/Reels** — viral visual content (the 3D map is inherently shareable)
- **WhatsApp/Telegram** — high-engagement groups per city
- **Reddit/HackerNews** — tech-early-adopter validation
- **SEO** — long-tail city+fest keywords (moat against competitors)
- **College Ambassadors** — ground presence in every campus

## Key Metrics

- DAU / WAU on the map (time spent > 30s = engaged)
- Events clicked / shared
- Organic vs referral traffic split
- Ambassador-driven signups
- Email collection rate from "Notify me"

## Growth Hypothesis

The 3D map is the wedge — it's visually differentiated enough to get initial shares. Once users land, the calendar + city-based aggregation creates retention. SEO builds the defensible moat over 6–12 months.
